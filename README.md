# 🐾 Projeto Adoções

Projeto de Adoções desenvolvido em **Java** no Eclipse, seguindo a arquitetura **MVC**, utilizando banco de dados **MySQL** com dados fictícios. A interface foi projetada com foco na clareza para observação dos dados (**Conceito 1**).

## 🚀 Tecnologias e Estrutura
* **Backend:** Java (JSP e Servlets).
* **Frontend:** HTML5, CSS3 e JavaScript localizados na pasta `WebApp`.
* **Banco de Dados:** Script SQL incluso para criação das tabelas no MySQL.
* **Codificação:** Configurado com `charset=UTF-8` para suporte total a caracteres especiais e emojis 🐾.

## 🛠️ Ajustes de Design Aplicados
* **Unificação Visual:** Títulos `h1` com `font-weight: 300` para um aspecto mais fino e moderno.
* **Centralização Dinâmica:** Uso de `container-voltar` com Flexbox para garantir que a navegação esteja sempre alinhada ao centro.
* **Leitura de Dados:** Espaçamento (padding) de `16px` nas tabelas para facilitar a conferência de informações.

## 📂 Como utilizar
1. Execute o script SQL no seu MySQL.
2. Importe a pasta no Eclipse IDE.
3. Configure o Apache Tomcat.
4. Acesse `http://localhost:8080/adocoes`.
